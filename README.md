# The Rock Guy TX - Website

Fast, mobile-first marketing and quote-request website for **The Rock Guy TX**, a Dallas-based bulk aggregate supplier (crushed limestone, gravel, sand, soil, mulch and compost) serving **Texas, Arkansas and Oklahoma**.

- Business: 1209 E Levee St, Dallas, TX · 817-454-5779 · Sales@TheRockGuyTx.com
- Domain: TheRockGuyTX.com
- Stack: plain HTML/CSS/JS generated by a small Node script. No framework, no database, no plugins, no monthly platform fee beyond the domain.

## Features

- Responsive design for phones, tablets and desktops, with a sticky Call / Free Quote bar on mobile
- 14+ product pages across Rock & Gravel, Sand, Soil & Fill, Mulch & Compost
- Online quote request form (material, quantity, delivery location, contact info) with a quantity calculator
- 12 DFW-area city pages plus Arkansas and Oklahoma pages for local search
- Specials page with auto-expiring offers (for example the Fort Worth pit grand opening)
- Photo gallery from the company Facebook and Instagram pages
- Social icons (Instagram, Facebook, WhatsApp) in the top bar and footer
- Easy content editing for the team through a browser-based admin at `/admin/` (Decap CMS)

## SEO, GEO and AEO

- Unique title, description, canonical, Open Graph, Twitter and geo meta tags on every page
- JSON-LD structured data: LocalBusiness, WebSite, BreadcrumbList, Product, Service (areaServed), FAQPage, ItemList, AboutPage, ContactPage
- Answer-first intro paragraphs and FAQ sections on product and city pages for answer engines and voice search
- `sitemap.xml`, `robots.txt` (AI crawlers allowed), and `llms.txt` are generated on every build
- Semantic HTML, one H1 per page, accessible forms, skip link and visible focus states

## Project structure

```
build.mjs            Static site generator (reads data/, writes dist/)
serve.mjs            Tiny local preview server for dist/
data/                Editable content: site info, products, areas, FAQs, specials
static/              Copied as-is into dist/: css, js, images, admin (CMS)
netlify.toml         Build and header configuration
```

## Run locally

Requires Node.js 18 or newer.

```bash
node build.mjs     # generates ./dist (sitemap, robots, llms.txt included)
node serve.mjs     # preview at http://localhost:4173
```

## Edit content

Without the CMS: edit the JSON files in `data/`, then rebuild.

- `data/site.json` - name, phone, email, address, hours, social links, top banner
- `data/products.json` - categories and products
- `data/areas.json` - cities and regions served
- `data/faqs.json` - frequently asked questions
- `data/specials.json` - specials (add `"expires": "YYYY-MM-DD"` to hide an offer automatically)

With the CMS: log in at `/admin/` (Netlify hosting with Identity and Git Gateway enabled).

## Deploy

### Vercel (config included in `vercel.json`)
1. Import this repository. Vercel reads `vercel.json`: build command `node build.mjs`, output directory `dist`.
2. Add the domain `therockguytx.com`. The client keeps ownership of the registrar and hosting accounts.
3. Quote and contact forms: by default they open a pre-filled email to Sales@TheRockGuyTx.com. For in-page submission with no mail app, create a free form endpoint (Formspree or Web3Forms) and put its URL in `formEndpoint` in `data/site.json`.
4. Specials can expire, so rebuild after an offer's end date (a Vercel Deploy Hook plus a daily scheduled call works well).
5. The `/admin/` CMS uses Netlify Identity and Git Gateway, so it works on Netlify only. On Vercel, edit the JSON files in `data/` or switch the CMS backend to GitHub with an OAuth proxy.

### Netlify (config included in `netlify.toml`)
Same build settings. Enable Forms, Identity and Git Gateway to use the `/admin/` editor.

## Before launch checklist

- Verify the ZIP code and map coordinates in `data/site.json`.
- Replace the logo and photos in `static/images/brand/` with the original files. The current copies are small web versions from the Facebook and Instagram pages.
- Add real photos for sand, soil and mulch (currently pattern art).
- Confirm hours, materials in stock, and Arkansas and Oklahoma delivery rules.
- Confirm the phone number is active on WhatsApp.
- Create and verify a Google Business Profile with the same name, address and phone.
- Submit `https://therockguytx.com/sitemap.xml` to Google Search Console and Bing Webmaster Tools.
